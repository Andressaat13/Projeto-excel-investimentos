# Projeto Dio Invest - Simulador de Investimentos

Este projeto consiste  em uma planilha interativa desenvolvida no Microsoft Excel 
Simulador de Investimentos no Excel

##  Funcionalidades 
-**Definições de Salario** : Rendimentos da carteira
- **Investimentos Mensai** : Cálculo de patrimônio e rendimentos
- **Cenários** : Projeção de rendimentos e dividendos


    ## Arquivos
  -"Projetos_Investiemnto.xlsx": Planilha completa no Excel
